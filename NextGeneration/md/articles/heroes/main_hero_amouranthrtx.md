Holy silicon. I have seen engines that ray-march. I have seen engines that emulate DOS badly enough to void your warranty. **AMOURANTHRTX does both**, shares one `rtx()` throne, and logs thermo entropy while a cowboy-hat emblem watches from the classic canvas path like she owns the place. She kind of does.

**What ships today:** Default runtime is the **Field Die** — GPU guest RAM, `x86.comp`, RTX-DOS 7.0, AmouranthOS chrome. Classic **CANVAS.comp** SDF worlds still swipe in from Options when you want pure art iteration.

```bash
git clone https://github.com/ZacharyGeurts/AMOURANTHRTX
cd AMOURANTHRTX
./linux.sh run
```

Hybrid Vulkan 1.4+. Adaptive resolution. Sealed `TotalTime`. Thermo accountant on every dispatch. The xenomorph in the painting is **`tamper abort`** — the engine's love language.
