## Visual DNA (read any Issue and you'll see it)

| Element | Examples in archive |
|---------|---------------------|
| **BIG GRIN title** | Jagged white or yellow letters, pink/red outline, blood drips (*Issue 10*, *HH7andfX0AM03Qb*) |
| **Issue badge** | `ISSUE 14`, `BIG GRIN #10`, `4.99 U.S.` price box (*Issue 1*) |
| **Grin entity** | Blue glowing eyes, impossible toothy grin, banana optional (*Issues 1, 3, 5*) |
| **Ornate frame** | Cracked glass, spiderwebs, chains, metal rivets, roses/eyes (*Issues 10, 20, 27*) |
| **Lightning** | Blue bolts from eyes and borders (*Issues 1, 3, 5, 10*) |
| **Speech bubbles** | Satirical one-liners, all caps (*Issues 1, 5, 14, 20*) |
| **Horror lane** | Ghost silhouette, dripping red, *The Sentence is Death* (*HH7andfX0AM03Qb*) |
| **Silly lane** | Angels, halos, priest horror face (*Issue 14*) |
| **Trading-card lane** | Parchment, filigree jar, cosmic green (*image(264)*) |

## Next Generation numbering

The **GitHub site** (`NextGeneration/assets/`) continues the series at **Issue 28**:

- Issues **28–30** → `assets/heroes/` heroes
- Issues **31–66** → `assets/wiki/{stack|physics|start}/<page>/` triptychs
- Issues **70–75** → `assets/ads/` magazine slots (optional)

Each NG cover is an **original AMOURANTHRTX advertisement** painted in BIG GRIN layout — not a re-upload of Issues 1–27. We **channel** archive composition; we **ship** Field Die truth.

## Text rule on paint

≤ **97 words** per cover. Headline + subtitle + tagline + credits only. Authoritative copy: [ON_IMAGE_TEXT.md](../meta/ON_IMAGE_TEXT.md).

If OCR disagrees with markdown, **markdown wins** — repaint to match.
