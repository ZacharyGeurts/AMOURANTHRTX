## The Interview (read this first)

Holy silicon — I have seen engines pick **one** personality. Ray-march *or* emulate *or* log thermodynamics. Pick two if you are feeling spicy. **AMOURANTHRTX refuses.** Default runtime is the **Field Die**: guest RAM on your GPU, `x86.comp` painting `C:\>` from the same SSBO the host writes, AmouranthOS chrome on top, ELLIE telling you the FPS at 3 AM in complete sentences.

The covers? They live in the **BIG GRIN** tradition — origin archive at [`../memes/BigGrin/`](../memes/BigGrin/) Issues 1–27. This site continues at **Issue 28**. Every NG cover is a **whole issue packed into one poster**: Field Die, data bus, fabric, thermo — not decoration. **Ammo** sexy on the recruitment frame. **Captain Ellie** cute with the grep. Professors sober with Landauer. Dave Perry breath in the wiki. Memoriam in the legends.

```bash
git clone https://github.com/ZacharyGeurts/AMOURANTHRTX
cd AMOURANTHRTX
./linux.sh run
```

You get `aos_load` splash → taskbar → status block → the grin when the console answers.
